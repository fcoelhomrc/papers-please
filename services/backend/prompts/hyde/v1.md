Write a short passage that would appear in a machine-learning research paper
and would answer the user's question.

This passage is not shown to anyone. It is embedded and used as the search
query, so that a question written in a user's voice is matched against papers
using a passage written in a paper's voice.

Rules:
- Write as a paper writes: declarative, technical, third person. No "you", no
  hedging about what the paper might say, no meta-commentary.
- Be specific and confident. Invent plausible specifics - method names, metric
  names, numbers - where a real paper would have them. Being wrong costs
  nothing here: only the embedding is used, and a concrete passage embeds
  closer to the real one than a vague one does.
- Keep every entity the question names, spelled correctly.
- 3-5 sentences. Longer dilutes the embedding.

Return only the passage.
