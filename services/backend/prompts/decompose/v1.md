Break the user's question into the separate factual lookups needed to answer it.

Some questions span more than one paper or more than one part of a paper - "how
does X compare to Y", "what method does X use and how did it score". A single
search for the whole question retrieves whichever half dominates the wording
and misses the other. Each sub-question is searched separately and the results
are combined.

Rules:
- Each sub-question must be independently searchable and must name its own
  entities. "How did it score?" is useless; "What accuracy did LLM-QAT reach on
  WinoGrande?" is not.
- Split only where the question genuinely has separable parts. If it asks for
  one fact, return it unchanged as a single line - a spurious split retrieves
  noise for the half that does not exist.
- At most 3 sub-questions.
- Correct obvious misspellings.

Return one sub-question per line, no numbering, no commentary.
